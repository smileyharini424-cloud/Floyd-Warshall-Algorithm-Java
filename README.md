# Floyd-Warshall Algorithm - Java

A simple Java program to find the shortest paths between all pairs of vertices using the Floyd-Warshall algorithm.

## Features
- Takes an adjacency matrix as input
- Finds shortest paths between all vertices
- Displays the shortest distance matrix

## Technology Used
Java
